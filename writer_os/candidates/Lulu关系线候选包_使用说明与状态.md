# Lulu 关系线候选包：使用说明与状态

## 地位

这是一次作者选择保留的 prewriting 结果入口。它只导航当前可继续发展的人物、情节块和世界线候选。

本文件主要导航 `candidates/` 中的未激活材料，同时指向已经形成的 opening draft 与 continuity checkpoint，便于候选避开既有连续性。只有实际位于 `candidates/` 的材料默认不加载、不采用、不分配世界线；链接到 draft 或 story state 不会把相邻候选一并激活。

以后若某项候选被作者采用，应按其当时作用进入 `creative_work/development/`、`presentation/`、`story_state/` 或 `drafts/`，并链接回相关候选；不要把整套候选一次性提升为 canon。

- `KCL`、`Kew Gardens`、`Wills Library` 与 `Keats Room` 可以作为作品地点；它们各自还具有校园、城市或文学功能。
- 伦敦公园和步行地理可以用于身体化叙事。

## 当前工作模型

- `Lulu` 是人物正式名称。
- 何须怨是玩家首先跟随的男主角和主要人类视角角色。
- Lulu 不是与 Interface 并排的普通 galgame 女主。她沿物理时间 `t` 与何须怨形成关系；终末 AI 沿 `τ` 可以读取相关世界线，Interface 只在有限的非初始世界线中物理在场。
- 玩家首先接触的世界线的邱园告白不可通过本作菜单取消；“不告白”只保留为可能独立制作的续作 IF。
- 玩家首见线在樱花树下完成告白，拒绝理由为 Lulu 已在一段关系中。
- 恋爱差异来自更早的关系史／历史因果差异；后来的英国／中国地理选择是另一条独立轴。
- 前期关系史由系统失灵、公共活动、maid café 拼桌、交通中断与短步行构成。
- Kew 是 Lulu 与何须怨第一次长时间单独相处。她确实想看樱花，何须怨只正式邀请一次，她在答应时已说明自己晚些时候另有安排。
- 正文目标语言为英文。现存中文对白只保存语义与节拍，正式英文直接创作，不先假定日语原文再翻译。

## 仍为 `TBD` 的创作决定

- Lulu 独立于恋爱线的长期目标、会主动发起的行动、与何须怨无关的错误，以及她在恋爱线中最终为什么选择何须怨。
- Lulu 的家庭结构，以及 `3＋1` 动漫画像中尚未确定的其余三项。
- 较早关系史分歧的具体历史事件，以及终末 AI 是旁观其结果还是有意造成它。
- 玩家在邱园固定告白之外能否改变语气、解释、拒绝后的行为以及改变呈现次序。
- 玩家是否与何须怨同时得知 Lulu 已有伴侣；当前倾向不设置可供侦探式回看的线索。
- Interface 何时向何须怨展示反事实幸福，以及何须怨是否走向她原先准备的安乐死结局。
