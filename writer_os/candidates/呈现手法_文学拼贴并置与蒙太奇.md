# 呈现手法：文学拼贴、并置与蒙太奇

## 地位

这是明确保留、当前未激活到具体场景的 presentation-method candidate。它记录一种可能适合高信息密度视觉小说的组织语言，不要求正作采用《荒原》式结构，也不构成固定 UI 方案。

## 工作区分

- **拼贴（collage）**：把来自不同文本、语体、媒介、时代或价值层级的碎片置于同一作品结构中，让接缝本身可见。
- **并置（juxtaposition）**：把两个或多个材料放在彼此附近，使差异、相似或互相改写的意义由相邻关系产生。
- **蒙太奇（montage）**：强调镜头、场景或信息单元的剪接与次序；它可以快速切换，也可以通过前后组合形成单个镜头没有的判断。
- **碎片化（fragmentation）**：描述材料呈断片、声音不统一或连接不完整的状态；碎片化可以是拼贴效果，但两者并非同义。
- **缺少显式过渡**：让读者承担填补关系的工作，是可选强度，不是拼贴必须完全取消叙事引导的规则。

## 对本项目的可能价值

- 把终末 AI 的宏观结构语言与一段沿 `t` 发生的细小人物经验并置，使尺度差异通过阅读而不是说明产生。
- 让同一个短句、图像或声音在不同世界线与 `π` 位置重复出现，随后因新信息被重新解释。
- 容纳理论、日常言语、系统记录、人物作品和环境细节，而不强迫它们先被统一成一种叙述语体。
- 用接缝表现记忆、世界线与主体版本之间既相连又不连续的关系。

## 框架与排序也是呈现制度

乔叟—济慈 *Hyperion* 诗篇—Simmons《海伯利安》借鉴线补入一项与拼贴不同的机制：材料被放进同一作品还不够，谁先讲、能讲多久、谁主持和评价、谁可以打断或要求重述，也会改变每一段材料的意义。框架因此不是中性的容器，而是分配叙述时间、注意与可信度的制度。

这对 `π` 尤其重要。同一组片段即使字面不变，出现顺序、前置人物 portrait、是否允许回读以及其后由谁回应，都可能把它从私人回忆改写成证词、数据、辩护、娱乐或共同体事件。看似随机的排序也不会自动消除人物既有的权威差异。

具体传统与使用边界见[乔叟—济慈 *Hyperion* 诗篇—Simmons《海伯利安》借鉴线](文学传统_乔叟_济慈Hyperion诗篇_Simmons海伯利安借鉴线.md)。本文件仍只保存通用呈现候选，不指定大策展人、主人公或 Interface 的框架角色。

## 使用边界

- 拼贴不等于把所有概念同时扔到屏幕上。作品已有较高设定负担；每次并置仍需有可感知的节奏、对比或回声，否则只会把解释责任转嫁给玩家。
- 高雅／通俗、宏大／琐碎的混合不应默认以一方嘲笑或认证另一方。日常材料可以改变理论意义，理论也可以改变日常材料的尺度。
- 本候选不预设分屏日志、歌词、哲学引文或故障艺术等固定 UI。任何第三方文本或受保护材料进入正作前，都需要另行确认授权与使用边界。
- 具体场景采用时，应转入 `creative_work/presentation/`，说明玩家此刻看见什么、材料怎样排序、是否允许重看，以及缺少过渡会造成何种预期理解。

呈现次序的现行边界见[玩家机位：悬置玩家具身镜头](../creative_work/presentation/玩家机位_悬置玩家具身镜头.md)。
