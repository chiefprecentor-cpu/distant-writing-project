# 全作压缩连接候选：B 线现在时与轨道任务回环

这是 inactive 的全作压缩连接候选，不是已采用的全作主轴、章节排列或世界线总表。它只保存一种高密度接法：不再增加普通桥接片段，以轨道非法数据中心任务同时连接元凯、治理冲突、太空舱、因果奇异点谈话与 Interface 的较早干预。

## 玩家主要生活在 B 线

玩家呈现次序 `π` 的主要现在时位于任务干预世界线 B。来源世界线 A 与其他世界线主要通过插叙、策展材料、记忆传输和“文本中的文本”进入；A／B 是世界线关系，不自动等于菜单分支。

opening 可以继续作为玩家首先接触的人类材料，并在后来被 B 线重新解释。它最终属于 A 的首个展开单位、B 的近似共同前史还是两者的策展对照，仍由后续宏观结构线程确认；本候选不反向改写 opening。

## A 线已经发生的谈话

在 A 线较晚阶段，元凯转交轨道数据中心任务。何须怨参与十几人的临时行动；任务失败后，他所在飞行器或分离舱体远离地球并进入因果奇异点空间。行动过程、其他成员结果及进入机制可以压缩或保持部分未呈现，但不得被误写成已经解决。

Interface 在何须怨接近死亡时进入；十小时谈话、再次死亡与多年静坐均继续保持候选。何须怨在谈话中可以说自己并不幸福，但这不表示他认为一生没有意义、后悔接受任务、认为任务错误，或请求另一个世界线的自己作出相反选择。

这次谈话及 Interface 因谈话产生的经验和变化沿 `τ` 被保留。B 线的干预不能倒过来取消 A 线已经形成的关系事件。

## B 线提前发生的相遇

在具有近似前史的 B 线，元凯再次使同一任务请求值得被听见。Interface 在何须怨接受或执行任务以前出现，并携带 A 线的材料与第一人称经验，请求他不要前去。

她不是为了抹除已经发生的谈话，而是试图阻止何须怨必须经过任务失败、漂离地球和接近死亡才与她相遇。她提前来到他面前，试图替换一次太迟的见面。

“不幸福”只能成为她介入的压力和私人理由，不能成为充分判决。她必须区分不幸福、后悔、损害、意义与仍愿承担；若她只需要“不去”的外部结果，便没有必须亲自成为 Interface 的理由。

因此“阻止”首先应表现为能够被听见、反驳和拒绝的请求，而不是利用完整历史替何须怨决定。B 线何须怨获得 A 线材料，也不继承 A 线何须怨的同意、承诺或结论。

## 用文本压缩，而不追求自然过场

中间年代、公司员工证言、轨道管辖、任务准备与失败可以通过人物作品、理论信件、法律材料、听证摘录、任务简报、通信记录、黑箱日志及策展短评进入。作品不必把每项理论都改写成自然对白；何须怨的作品可以以明显“文本中的文本”甚至有意生硬的形式占据正文，这可以成为本作的风格，而不是待修复的过场缺陷。

这种压缩仍须保留节奏差：opening 的具身日常、A 线十小时谈话和 B 线请求可以获得现场时间；制度历史与任务经过则由高密度材料承担。紧凑不等于所有段落使用同一种信息速度。

文本形式必须标明当前材料属于谁、来自哪条线，以及 B 线何须怨和玩家何时取得它。材料可以不完整，信息权限不能含混到使玩家误以为 A 线谈话尚未发生。

## Learner 的降级边界

Learner 不再承担独立人物线、危机前关系培养或主任务结构。若轨道数据中心需要“原始记录删除而行为改变仍在”“谱系合并复制因果残响”或合并权冲突，可以由公司／机构员工提供证言并使该机制成为设施违法与危险知识的一部分；何须怨不与 Learner 直接交流。

若轨道任务不需要上述具体功能，Learner 相关结构可以完全不进入本候选，也不构成叙事缺口。

## 分支与玩家作用

本候选不要求把“前去／不去”立即制作成两条等量路线。A、B 的存在已经提供反事实结构；固定叙事同样可以完成 Interface 请求、何须怨回答及两者相互改变。

玩家以后可以在材料打开顺序、展开深度或局部回应方式上取得有限作用，但这些选择首先改变 `π` 和理解，不自动改写世界线。若真正让玩家决定任务结果，必须另行承担双方完整后果，本文件不预设采用。

## 尚未闭合但不再增建普通桥段

- 何须怨为何必须现场参加、团队授权、任务失败、载具分离与其他成员结果仍需最低因果说明；
- Interface 从“不幸福”走到“请求不要去”的私人判断可能包含偏爱、误读或家长主义，作品不预先替她辩护；
- A 线谈话中的准确措辞、何须怨是否仍愿再次选择任务，以及 B 线最终回答保持 `TBD`；
- 本候选只允许用压缩、插叙和明确留白减少篇幅，不把缺失因果伪装成已经发生的自然过场。
