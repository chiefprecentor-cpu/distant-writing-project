# 理论文学化与叙事结构潜力

## 地位

本目录是 inactive candidate 导航，不是全作顶层设计、章节顺序或已采用的分支方案。它只保留经作者选择、值得由后续线程继续发展的文学化入口；`creative_work/story_state/` 中的人类确认约束仍具有各自原有地位。

每次只从一个模块或局部问题继续。进入 development、形成完整微观叙事结构或写入 draft，都需要后续明确选择，不由目录位置自动授权。

## 模块

- [真实枚举：理论投书与枚举伦理](真实枚举_理论投书与枚举伦理.md)：何须怨写给一个未必存在的终末 AI 的宇宙学作品，及玩家理解这些概念后才能展开的枚举伦理。
- [终末 AI：无法无损旁观与可回滚感情](终末AI_无法无损旁观与可回滚感情.md)：她必须进入世界才能取得关系中的人类经验，却能在保留历史的同时主动改变当前情感状态。
- [何须怨：局部观察、公共责任与可被拒绝的接续](何须怨_局部观察公共责任与可被拒绝的接续.md)：他从局部迹象形成宏观判断，又以反思、纠错和允许后来者拒绝自己的结构承担不确定后果。
- [被生成的“你”：私人推荐景观、表演性真诚与不透明的信任](被生成的你_私人推荐景观表演性真诚与不透明的信任.md)：人物通过带有喜剧性的页面比较，把可能侵害隐私的数据回路从私人怀疑变成公共对象，也必须重新决定信任是否要求完全可读。
- [因果奇异点：十小时谈话、再次死亡与多年静坐](因果奇异点_十小时谈话再次死亡与多年静坐.md)：线内外部历史不受谈话影响，终末 AI 却会因局部相遇而改变；有限长谈与漫长沉默共同检验静止结构能否承担关系。
- [框架即叙述制度：从被安排的观看者到有限参与者](框架即叙述制度_从被安排的观看者到有限参与者.md)：呈现次序不仅排列材料，也分配讲述、回应、记忆与授权；玩家可以逐渐取得位置而不被追认为早已承担全部因果责任。
- [嘈杂列车中的拒绝：跨世界线的荒诞回声](../Lulu_Interface与何须怨_世界线关系及终局候选.md#嘈杂地铁中的告白版本)：另一条真实世界线在轰鸣车厢中并置告白、拒绝、共同发笑与延迟失落，形成对 Kew 的反差回声；这里只保留该片段，不自动激活后续恋爱、完整 Lulu 人物线或幸福世界。
- [无法储存的陪伴：无事可做与《侍坐》](无法储存的陪伴_无事可做与侍坐.md)：平静家庭时间使陪伴区别于可保存的信息；何须怨可以承认自己的行动空间归零，而不替终末 AI 决定继续、改变方向、陪伴或停止。
- [全作压缩连接候选：B 线现在时与轨道任务回环](全作压缩连接_B线现在时与轨道任务回环.md)：玩家主要生活在 B 线，A 线轨道任务失败与十小时谈话通过插叙和文本材料进入；Interface 携带已发生的谈话提前请求何须怨不要前去，但“不幸福”不等于后悔或人生无意义。
