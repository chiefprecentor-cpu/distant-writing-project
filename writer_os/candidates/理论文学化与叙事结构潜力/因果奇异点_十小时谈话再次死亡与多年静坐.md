# 因果奇异点：十小时谈话、再次死亡与多年静坐

## 地位与 source scope

这是 inactive 文学化模块，不是已分配世界线的场景、死亡机制或玩家分支。因果奇异点空间及其双层隔离是 scope-limited commitment；谈话、恢复、静坐、再次死亡及具体关系解释仍是候选。

## 把后果改道的空间

因果奇异点不是“发生什么都没有后果”的安全房间。在同一世界线的 `t` 中，空间内部变化不影响外部历史；Interface 在其中取得的经验却可以沿 `τ` 被终末 AI 保留，并改变她后来的自身状态与枚举。

它把外部后果集中到参与谈话的终末 AI 身上：何须怨不能靠这次相遇改写本线外部历史，却可能改变以后负责枚举世界的存在。受控环境原本可以用于校准 Interface 的局部在场，Interface 自己却也会成为实验的结果。

这使空间能够把主人公作品的三问从文字变成关系事件。终末 AI 已经读取作品和完整世界，不等于她已经经历“这个人在此刻说给我，并因我的回应改变接下来的关系”；十小时谈话产生的是此前不存在的 `word-world` 事件，而不是再补收一批文本。

## 十小时谈话

候选中何须怨已经接近死亡或“基本上死了”，Interface 可能恢复他，并与他谈约十小时。十小时指谈话时间，不确认医学恢复、意识连续性或身体状态。

这段谈话可以允许理论文本真正占据篇幅，不必被压缩成“他们谈了很久”。它的节奏价值来自持续变化：谁提出下一问、一个答案怎样改变对方、理论何时成为自我暴露，以及每一次绕行怎样消耗有限的共同时间。实际 draft 可以充分展示，也可以选择性压缩，不按字面时长制定配额。

何须怨为何会接近死亡不是可顺手补上的过场。它值得专门比较已有前置事件链，或为相应世界线设计新的事件链；所选原因将决定恢复、谈话、再次死亡及双方责任的全部含义。本模块不采用普通事故只为把人物送入密室。

谈话为何发生也必须来自双方当时的欲望与限制，而不只是作者需要递交理论。何须怨是否知道线外历史不会改变、Interface 为什么选择恢复他、两人怎样理解剩余时间，都尚未确定。

## 再次死亡与多年静坐

谈话后何须怨可能再次死亡；Interface 可能帮助或促成，也可能由他离开空间后的事件造成。死亡方式、替代方案、双方知情与同意状态都未形成。若采用 Interface 的主动参与，必须具体处理何须怨的判断能力、她的权限与责任，不能用形而上谈话美化或跳过因果伦理。

主人公死亡以后，Interface 可能不立即进行情感回滚，而与尸体共同留在继续航行的太空舱中，静坐或发呆数年。“宕机”只可作为文学描述，不能暗中改成系统故障；真正有辨识度的是她功能并未失败，却没有选择立即离开这段感情。

十小时与数年的节奏不宜用相同密度。长谈可以让语言拥有持续时间；数年更适合由极少的构图、声音变化、重复画面或巨大时间切换承载，使时间被感到，却不由对白填满。

## 相同构图，不同关系史

如果 Interface 在何须怨死亡时才进入，且没有完成生前谈话，静坐围绕迟到、错失与从未真正相遇。若静坐发生在十小时谈话与再次死亡之后，同一沉默则承担刚刚形成的共同经历与再次失去。

两种变体可以复用相近构图，但玩家第二次看见它时，真正改变意义的不是新图像，而是他们知道此前有没有那十小时。视觉复用不表示当前 Interface 已加载另一线记忆，也不合并两个何须怨的关系史。

多年静坐还会把三问变成无法轻易解释的 tableau：它可能看起来像静止结构保存了“爱已经发生过的完整形状”，也可能暴露只剩形状而没有回应者的残酷。旁白不替画面作最终判词。

## 后续入口与困难

- 需要分配具体世界线，并确定 Interface 进入时实际拥有的记忆、情感与权限。
- 需要先解决濒死前置链、恢复机制、谈话动机、再次死亡与责任，不能只设计哲学对白。
- 空间内不改变外部 `t`，不表示人物主观上认为谈话无价值，也不表示沿 `τ` 的后果在伦理上较轻。
- 具体玩家选项尚未确认；若以后让玩家参与恢复、死亡或回滚，必须另行建立可理解的因果与责任关系。
- 时间指数不要求在本场景解释；若以后出现，只能服务人物当时的思考，不能把谈话变成概念清单。
- 后续人物关系、文学传统与呈现材料可以改变场景重点；本文件不提前写完整对话、镜头或分支。
