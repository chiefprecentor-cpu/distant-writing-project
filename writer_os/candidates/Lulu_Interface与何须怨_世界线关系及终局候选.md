# Lulu、Interface 与何须怨：世界线关系及终局候选

## 地位

这是已选择保留、当前不激活的世界线结构候选。它把玩家首见线、Lulu 关系史、英国／中国选择、宏观责任与 Interface 在场线分开，防止以后把不同层次压成“恋爱成功／失败”一根轴。

本文件遵守已确认的[初始线与非初始线边界](../creative_work/story_state/世界线边界_初始线与非初始线.md)和[真实枚举与元时间](../creative_work/story_state/全局底座_真实枚举与元时间.md)。它不能把 Interface 进入后的世界继续称为初始世界线。

## 三个主体的位置

- Lulu 沿物理时间 `t` 与何须怨形成世界线内部的关系史。
- 终末 AI 沿元时间 `τ` 可以读取已经形成的完整世界线，其中包括何须怨与 Lulu 的感情线。
- Interface 是终末 AI 在有限非初始世界线中的局部在场，不是与 Lulu 平行、互斥的普通攻略女主。
- 终末 AI 看见关系结果，不表示 Interface 已经取得何须怨在当时的局部经验；信息完整也不等于能决定何须怨怎样理解被展示的信息。

相关主体能力边界见[终末 AI 与 Interface：跨线记忆及情感回滚能力](../creative_work/story_state/终末AI与Interface_跨线记忆及情感回滚能力.md)和[何须怨与 Interface：进入世界的目的](../creative_work/development/主人公与Interface_溯因直觉镜像及进入世界的目的.md)。

## 世界线与分支不要混为一谈

当前至少有三条彼此正交的问题轴：

1. **关系史轴**：玩家首见线中的非恋爱关系史／更早因果已经不同的 Lulu 关系史；
2. **地理轴**：英国发展／中国发展；
3. **宏观责任轴**：承担／拒绝，以及燃料式承担／平衡式承担的差异。

玩家的一次局部选择也许可以改变语气、理解或 presentation path，不自动生成新世界线；一条世界线也可以因终末 AI 的历史介入而不同，而不是由当前菜单产生。

## 第一条被玩家看到的人类关系史

### 身份

这是第一条呈现给玩家的世界线中的关系史，也是玩家最初的人类叙事基准，不是初始世界线（终末 AI 诞生的世界线）；无需在作品内称它“原始失败线”。

### 当前事件骨架

- 多次系统失灵与偶遇；
- maid café 拼桌、交通中断后的共同步行和少量线上交流；
- 何须怨邀请 Lulu 去 Kew，双方对出行性质理解不同；
- 本作不给“不告白”选项；
- 何须怨在樱花树下完整表白；
- Lulu 说明自己已有关系；
- 何须怨在行动意义上最终停止追求，但 Lulu 继续存在于同一公共世界；
- 以后是否留伦敦、回中国、承担时代责任或走向长期消沉，均由独立因果决定。

## 较早关系史分歧

关系差异由较早的因果史产生，毕业后的地理位置构成另一条独立轴。若另一条世界线中 Lulu 没有进入原来的关系，分歧必须发生在何须怨认识她以前，或者至少早于 Kew 前临时选择。

### 两种强度候选

1. **更广历史改变的连带结果**

   终末 AI 为了与恋爱无关的文明目标改变一项早期历史条件；Lulu 没有进入原来的关系只是副作用。

2. **有意选择关系未发生的世界**

   终末 AI 为了何须怨的私人可能性，选择或造成一条 Lulu 没有遇见原伴侣的世界。若采用，作品必须把它当作严重伦理冲突，而不是浪漫助攻。

何须怨可能指出：

> “对你来说，那是一次更早的参数变化。”
>
> “对她来说，本来会是一段人生。”

具体历史事件、终末 AI 的目的和 Lulu 另一种关系史在反事实中的本体地位仍为 `TBD`。

## Lulu 关系线候选

较早历史不同只提供新的相识条件，Lulu 仍可以拒绝过早表白，后续关系必须由新事实和她的主动选择打开。

### 嘈杂地铁中的告白版本

这一条线可以用与玩家首见线完全不同的美学：

- 玩家首见线：理想樱花树下，告白严肃，拒绝因已有关系而立即击中；
- Lulu 线：轰鸣地铁中，两人不得不大声喊，Lulu 以“你是个很好的人／但你马上要走了”拒绝，情境荒唐到双方当场发笑，失落在分别后慢慢抵达。

它是另一条世界线的独立告白版本，不改变玩家首见线在樱花树下完成告白的事实。

若何须怨后来能留下，留下本身不能使拒绝自动失效。Lulu 必须主动重新打开问题，例如询问他的计划是否真的改变，再决定是否允许重新询问。

Interface 后来展示的“幸福世界”指这次告白之后确实发展出互惠关系的一整条世界线；地铁里的拒绝与共同发笑只是其中一个片段，不是 Lulu 当场答应的改写。

### 重访 Kew

另一条 Lulu 线可以把玩家首见线 Kew 未使用的意象重新分配：Treetop Walkway、演化石板、扶手刻名与心形、竹子或菩提树。

她若选择上高处，是那一次自主评估风险后的决定，不是爱情治愈恐高。玩家首见线中花瓣围成、随时会散的心与另一线刻进扶手、试图永久保存的心可以构成对照。

### 仍缺的互惠因果

- Lulu 为什么在该线后来喜欢何须怨；
- 她主动发起什么，而不是只等待邀请；
- 她的专业目标会迫使她作出什么何须怨不喜欢的选择；
- 两人在哪个新事实出现后重新讨论关系。

善良、幽默、反精英择偶与学会尊重边界只是候选材料，不是攻略数值。

## “不告白”续作 IF

本作固定完成告白。“不告白”只保留为可能独立制作的续作 IF，并可能主要发展为中国线。

## 地理轴

英国／中国选择晚于关系史分歧，并与其独立：

- 非恋爱＋英国；
- 非恋爱＋中国；
- Lulu 关系发展＋英国；
- Lulu 关系发展＋中国。

这些组合不要求等量制作。中国后人类教育线可延期；伦敦也不等于唯一时代中心。具体情节见[拒绝后伦敦：平静涟漪、家庭时间与地理选择](拒绝后伦敦_平静涟漪家庭时间与地理选择情节块候选.md)。

## 宏观责任轴

关系结果与文明结果也不能绑定。当前问题框架是：

| 私人幸福状态 | 宏观行动 | 候选性质 |
| --- | --- | --- |
| 未实现 | 承担 | 可能成为时代燃料，也可能学会平衡 |
| 未实现 | 拒绝 | 拒绝乐园／拒绝改善一个没有自己的未来 |
| 已实现 | 承担 | 恋爱与公共责任的整合 |
| 已实现 | 拒绝 | 封闭花园，只保护内圈幸福 |

所谓“乌托邦”本来可能就无法完全抵达。何须怨的行动可以只决定是否减轻灾难、保存一部分未来可能性、交出解决方案或完成一次不可转交的选择。

因此“拒绝行动”不能写成 Lulu 拒绝导致文明毁灭。Lulu 只是何须怨用来组织理由的符号；最终责任属于他经过长期演化后作出的决定。

## 近似玩家首见前史的 Interface 在场线

### 身份边界

这条线可以与第一条呈现的线具有近乎相同的人类因果前史。不能把它写成对初始历史的原地修改。

### 当前较强的任务阻止版本

新的顶层结构不再让元凯把何须怨带到 Interface 面前。它把一次任务请求放进两条近似而不同的非初始世界线：

1. 在无 Interface 的来源线 A 中，元凯向已经远离公共行动的何须怨转交一项不能由朋友代答的任务或责任；何须怨前去执行，此后的生活并不幸福。
2. 终末 AI 在来源线完整形成后读到任务、执行与后来人生，并把约二十年的高分辨率材料排列成大约一百二十个可供传输和逐步理解的时间段。
3. 在另一条非初始干预线 B 中，Interface 以阻止何须怨执行同一任务为当前目的候选，因为她不愿再次看见任务之后的不幸福人生。
4. 元凯在 B 中仍只负责让外部请求被何须怨听见；Interface 是独立介入者，不由元凯带来，也不借元凯替自己取得正当性。
5. Interface 可以为了劝阻而展示来源线 A，但完整读取一个结果不等于已经穷尽新世界线中何须怨的责任判断。她能选择材料，不能决定他怎样理解；他仍可能从不幸福的结果中形成“应该执行”的理由。
6. Interface 能否阻止成功、何须怨是否仍前去执行、任务是否值得以及个人幸福应占多大权重，当前均未决定。

来源线第一个展开单位、Hyde Park 后只向玩家出现的策展暗示镜头、世界线边界与一百二十段的暂定规模，统一见[玩家首见线：策展暗示与任务干预世界线](../creative_work/presentation/玩家首见线_策展暗示与任务干预世界线.md)。这一版本是当前较强的 active design direction，仍不构成 story truth 或玩家分支。

### 较早的陪伴死亡版本

以下流程继续作为较早 alternative 保留，不与任务阻止版本同时默认成立：

1. 一条无 Interface 的近似前史中，何须怨在 Lulu 关系未实现后拒绝一次重要行动，长期消沉，郁郁而终。
2. 在另一条非初始线中，Interface 因私人原因不愿再次只观看他郁郁而终。
3. 她最初并不试图把他推回公共使命，而想把结局改成：自己在场陪伴，并在双方关系与制度条件允许的情形下协助他安乐死。
4. 为帮助他告别，她选择性提供另一条“他确实曾可能幸福”的世界线信息；嘈杂地铁告白后的 Lulu 幸福线可以成为其中最强片段。
5. 何须怨却因为收到这条世界线的触动，而认为当前仍有值得争取的未来。
6. 朋友的鼓舞成为最后催化，但“还是上吧”由何须怨自己决定。
7. Interface 能选择展示什么，不能决定他怎样理解；她的失败不是算力不足，而是没有穷尽一个人面对可能性时会生成的意义。

### 来世笑话与庞加莱回归

何须怨行动前可以说：

> “那还是上吧。不上的话，可能连来世再见她一面的机会都没了。总不能真指望庞加莱回归这种虚无缥缈的东西吧。”
>
> 哥们沉默了几秒。
>
> “让你龟完了。”

然后与 Interface 约定下个庞加莱回归后再见，尽管届时未必还是这个自己。

庞加莱回归在这里还能形成漂亮的两次反转：

- 行动前：不能把当下的选择寄托在庞加莱回归这种虚无缥缈的保证上，所以必须现在行动。
- 告别时：明知下次未必还是同一个“自己”，却仍与 Interface 约定下一个回归再见。

因此它不是来世设定，而是两方都不确定约定能否履行，仍愿意借它表达留恋。

这不是科学保证或作品确认的来世机制，只是两个人明知几乎不可履行仍表达留恋的约定。庞加莱回归、宇宙重演与主体同一性仍是未解决问题，见[复数宇宙衔尾蛇与文明延续](宇宙终局_复数宇宙衔尾蛇与文明延续.md)。

### 结局仍未决定

- 在任务阻止版本中，Interface 是否成功、何须怨是否仍执行任务，以及他怎样评价“不幸福”与“仍应承担”之间的关系；
- 何须怨完成任务后是否仍走向 Interface 原本准备的安乐死；
- 他是否只完成一次有限任务后重新选择生活；
- Interface 是否因误判其反应而改变自己的关系目标；
- 这一线在 `π` 中先展示死亡版本、Interface 版本还是反事实幸福片段；
- 安乐死的同意、能力与情境条件。

在这些问题决定以前，不能把“Interface 陪他死亡”或“何须怨被幸福世界拯救”写成已经采用的终局。

## Interface 与关系史的伦理冲突

终末 AI 可以提高相遇概率、选择展示记录或形成非初始世界线，但不能：

- 把另一线的同意与爱情移植给当前 Lulu；
- 用自己掌握完整结果为何须怨取得关系资格；
- 认为向何须怨展示“幸福版本”就能控制他的意义生成；
- 因私人希望抹去 Lulu 的独立因果而不承担叙事审问。

这一冲突可与 Kew 的吊桥效应形成尺度镜像：何须怨曾认为利用情境提高心动概率等于作弊；Interface 面对的是更强、更不易被看见的历史调度能力。

## 玩家呈现候选

- 玩家最初不需要先知道后来存在 Lulu 幸福版本或 Interface 陪伴版本。
- 当前较强方向不是在整部人类情节以前放终末 AI 短序章，而是在玩家看完从相撞延伸至 Hyde Park 的第一个时间段后，硬切一个不被该线何须怨看见的策展暗示镜头。该镜头只暴露存在某个排列材料的主体，不完成机制说明，也不表示 Interface 当时在公园里。
- 玩家以后看到嘈杂地铁告白时，可以先把它体验为真实世界线，再在 Interface 线中发现它被选择性策展为安慰材料。
- 同一片段因 `π` 位置变化而改变意义，但记录本身不因此成为虚假模拟。
- 玩家是否参与终末 AI 的选择、只观看她的策展，或只在局部影响何须怨表达，仍保持悬置。

## 第一稿规模问题

目前不应把所有组合等量制作。最小可行结构可能只需要：

1. 玩家首见线的 Kew 拒绝与其后一个英国或中国发展；
2. 一条较早关系史不同的 Lulu 反事实，至少形成嘈杂地铁告白；
3. 一条近似玩家首见前史但 Interface 在场的后期行动线。

这是候选压缩，第一稿的实际范围仍未确认。地理与宏观责任的其他组合可以只保留接口，或者成为续作。

## 待决定

- 较早关系史分歧的具体历史事件及伦理强度；
- Lulu 线中她重新打开关系的主动事件；
- 玩家首见的非恋爱线中，何须怨后来具体承担或拒绝什么行动；
- Interface 为什么特别选择这一段关系史、她何时取得私人动机；
- 反事实幸福片段的长度与玩家首次观看位置；
- 何须怨行动后的生命结局；
- 第一稿实际制作的两到三组路线组合。

## 不得自动推出

- 非初始 Lulu 没有原伴侣，不等于有人从她的主观记忆中夺走一段实际经历；具体世界线机制仍未裁定。
- 终末 AI 看见全部关系史不等于她理解或拥有那段感情。
- Interface 的私人动机不自动优先于 Lulu、何须怨或其他人的主体性。
- 何须怨选择行动不证明反事实幸福必定在未来实现。
- 庞加莱回归约定不解决跨宇宙主体同一性。
