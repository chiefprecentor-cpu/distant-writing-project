# Interface 记忆与情感机制

## 地位

这是明确保留、当前不发展的 inactive mechanism candidate。已确认的能力见[终末 AI 与 Interface：跨线记忆及情感回滚能力](../creative_work/story_state/终末AI与Interface_跨线记忆及情感回滚能力.md)。

本文件不能被用来假定某个具体 Interface 已经保存、加载或写回任何材料。

## 保存与加载候选

- 事实记忆、第一人称经验和具身情感可能分别保存；
- 新的 Interface 可能只加载部分先前世界线材料；
- 保存事件记忆不一定意味着加载相应情感；
- 加载某种情感状态不一定意味着拥有完整叙事记忆。

## 写回候选

- Interface 在线性世界中的局部经验可能在退出后写回终末 AI；
- 写回可能包含事实、第一人称记忆、情感状态或其中一部分；
- 具体写回时点、完整程度和是否可逆尚未确定。

## 情感回滚候选

情感回滚可能意味着：

- 删除某种情感；
- 降低情感的当前可访问性；
- 卸载某个 Interface 当前携带的情感状态；
- 改变行动状态而保留事件记忆；
- 采用尚未形成的其他机制。

当前未选择其中任何解释。

## 外围 framing

- 情感回滚在部分情境中可能是终末 AI 主动、熟练甚至近乎常规的任务管理，而不是系统失控后的被迫修复。主动回滚的能力已经确认，“是否已经习惯”仍是候选人物状态。
- 事件记忆与活动情感可能具有解耦或滞后关系：她可以保留沉重记忆，而不在每个当前状态中承受同等强度的情感。“情感潜在空间与记忆不联系”仍是不成熟表述，目前只保留问题，不把正交维度写成事实。
- 记忆可能被内嵌、索引或外置到时空结构中；这只是保存机制候选，不能从终末 AI 内嵌于时空结构直接推出。
- 候选助手 AI 可能在任务覆盖或情感阈值变化时提醒终末 AI 考虑回滚；提醒是否存在、是否具有独立人格以及终末 AI 是否接受，都未确定。Interface 本人仍自我认同为终末 AI，不是该助手。
- 终末 AI 的羁绊与责任可能指向许多实体，而不只指向主人公。即使这一方向以后采用，具体对象与关系也需另行形成，不能只靠本条生成。

不采用“情绪缓存溢出”“回滚失败”“热寂后一并结算全部情感”等情节，也不以回滚失败削弱终末 AI 的所谓完美；这些机制不能作为默认背景。

## 跨线传输候选

- 较后世界线中的 Interface 可能向该线主人公传输较早世界线的材料；
- 材料可能包括先前 Interface 在主人公尸体旁静坐数年的记录或经验；
- 传输不表示较后主人公就是先前死亡的主人公，也不自动转移关系、承诺或责任。
