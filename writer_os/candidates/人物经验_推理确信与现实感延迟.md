# 人物经验：推理确信与现实感延迟

## 地位

这是一个未分配具体人物或事件的 phenomenological candidate。它不是医学或心理学模型；具体人物、世界线、触发事件与叙事功能均为 `TBD`。

## 核心经验图像

当一个事件或推理结果与人物此前的经验框架严重冲突时，人物可能依次经历：

1. 否认或寻找普通解释；
2. 在某一瞬间以狂喜、恐惧或崩塌般的强度确信“它确实发生了／这个推理确实指向这里”；
3. 认知上仍然无法否认，感官与情绪上的真实感却开始退远或麻木。

最简短的文学表述是：

> 发生了，但是感觉起来不像现实。

这一错位的重点不是人物不知道事实，而是“知道”与“活在这个事实里面”没有同步完成。命题判断可能已经跨过门槛，身体、情绪和日常世界仍停留在旧框架中。

## 可能用途

- 主人公从零散迹象推出一个过于宏大的结论以后，面对自己的推理能力与有限行动位置之间的断裂；
- 人物第一次确认终末 AI、真实枚举或世界线接替并非隐喻；
- Interface 已经拥有命题知识，却第一次从局部在场中取得“这件事正在发生在我身上”的指示性理解；
- 角色在经历不可逆事件后仍能复述事实，却暂时无法让事实取得日常现实的质地。

## 边界

- 这不是固定三阶段诊断，也不声称麻木必然是某种单一“生理保护机制”。
- 不把强烈确信自动当作推理正确的证据；人物可能确信错误，也可能在结论正确时误解原因。
- 它不同于主人公的“地震仪式敏感”：后者发生在从微观迹象感受未来走向时，本候选更关注结论已经形成后，认知与现实感怎样错位。
- 若用于 Interface，需要与“命题上知道，第一人称地读懂”的首次进入候选核对，不能只把人类经验原样贴到非人主体上。
