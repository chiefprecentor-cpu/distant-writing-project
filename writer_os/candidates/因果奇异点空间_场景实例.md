# 因果奇异点空间：场景实例

## 地位

这是围绕已确认 local commitment 保存的 inactive scene candidates。空间本身及因果隔离规则见[局部设定：因果奇异点空间](../creative_work/story_state/局部设定_因果奇异点空间.md)。

下列实例没有被分配给具体世界线，也不构成 local truth。

## Interface 出现场景

- 终末 AI 很可能在相关场景中成为 Interface。
- Interface 是否干预主人公身体尚未确定。
- Interface 的出现、信息传输与身体干预是不同事件，不能自动合并。

## 十小时谈话候选

- 在一组候选情节中，主人公已经接近死亡或处于场景所称的“基本上死了”的状态。
- Interface 可能恢复主人公，并与他进行约十小时谈话。
- “十小时”在当前候选中指谈话时间。
- 恢复的医学、意识与个体连续性机制仍未确定。

## 多年静坐候选

- 主人公死亡后，Interface 可能与尸体共同留在继续航行的太空舱中。
- Interface 可能没有立即情感回滚，而是在主人公身旁静坐或发呆数年。
- 这一场景可以发生在没有完成生前谈话的版本，也可以发生在十小时谈话之后。
- “宕机”目前只是文学化描述，不是已确认的技术故障机制。

## 两种静坐前史的外围 framing

以下解读用于保存两个场景变体为何不只是同一画面的重复；它们不规定最终文本必须采取的情感解释：

- 如果 Interface 在主人公死亡时才进入，且此前没有完成生前谈话，静坐可以围绕迟到、错失与无法相遇展开。
- 如果静坐发生在十小时谈话和再次死亡之后，同样的沉默可以回应刚刚形成的共同经历与未完成关系。

两种变体以后可以复用相近构图，但视觉复用不表示它们拥有相同的关系史，也不自动表示当前 Interface 已经加载另一条世界线的具体记忆。跨线记忆能力与某个实例实际携带什么仍需分开。

## 死亡路径候选

- 主人公在谈话后再次死亡；
- Interface 可能帮助或促成死亡；
- 主人公也可能离开因果奇异点空间后继续漂流，并因尚未确定的事件死亡；
- 具体死亡方式、双方知情状态与玩家选择均未确定。
