# 玩家首见线：策展暗示与任务干预世界线

## 地位与范围

本文件记录已经确认的 opening 呈现选择与当前采用的 A／B 后续接法：Hyde Park 睡眠以后保留独立终端硬切；玩家的主要叙事现在时随后稳定进入任务干预世界线 B，并由 Interface 打开来源世界线 A 的材料。opening 本身最终属于 A 的首个展开单位、A／B 的近似共同前史还是策展对照，仍为 `TBD`；当前接法也不是全作章节表或玩家分支树。

opening 的精确文本见[英文近定稿](../drafts/开幕_流水冷开场_相撞与讲座.md)，跨章事实见[开幕世界线状态](../story_state/开幕_相识至HydePark与终端硬切.md)。本文件只讨论玩家实际接触材料的次序 `π`；世界线和 Interface 的能力边界分别见[世界线边界：初始线与非初始线](../story_state/世界线边界_初始线与非初始线.md)、[终末 AI 与 Interface：跨线记忆及情感回滚能力](../story_state/终末AI与Interface_跨线记忆及情感回滚能力.md)与[玩家机位：悬置玩家具身镜头](玩家机位_悬置玩家具身镜头.md)。

## 已确认的人类 opening

- 玩家首先观看一段没有 Interface 在何须怨所在物理现场出现的人类生活，从相撞延伸至 Kew 拒绝、伦敦余波、Hyde Park 睡眠与终端硬切。
- 具体情节、心理权限变化、求职菜单与人物关系不在本文件复述，以近定稿及其 story-state checkpoint 为准。
- 元凯没有在 opening 把何须怨带到 Interface 面前；他后来在 B 线参与轨道任务的证据与行动论证并转交请求，但仍只使请求值得被听见，不替何须怨决定。

## 当前采用的来源／干预接法

### 来源世界线 A

- A 是一条没有 Interface 提前干预轨道任务选择的来源世界线，不是终末 AI 诞生的初始世界线，也不因后来被读取而变成 B。
- 在 A 的较晚阶段，元凯转交轨道数据中心任务，何须怨接受并参与。行动目标与最低证据传输成功，完整原件回收和何须怨撤离失败；他的舱体是唯一未撤离的载人单元。何须怨死后随舱体长期漂流，进入因果奇异点，再由 Interface 复活并进行约十小时谈话。任务与谈话的现行约束集中见[主人公与 Interface](../development/主人公与Interface_溯因直觉镜像及进入世界的目的.md)和[因果奇异点 story state](../story_state/局部设定_因果奇异点空间.md)。

### 终末 AI 的读取与策展

- 终末 AI 在潜入 A 以前读到的是沿 `τ` 与 A 相邻的更早世界线，而不是 A 自身。那条更早线已经形成完整四维世界快照，也是她第一次成为 Interface 具身迟到并长期静坐的世界线；A 是第二次深潜。A 线因果奇异点中的十小时不在她此前读到的记录中，而是局部 Interface 沿 `τ` 新取得的经验。
- A 线十小时完成以后，终末 AI 可以把包含这次新经验的 A 线材料排列给后来 B 线中的何须怨。预先读取相邻更早线、在 A 中取得新经验及后来策展 A 是三项先后不同的事件。
- Hyde Park 后插入的暗示镜头可以发生在终末 AI 已经完成整条来源线的读取与材料排列之后；它在 `π` 中出现得早，不表示终末 AI 当时只知道 Hyde Park 以前的历史。
- 终末 AI 将来源人生排列为可供另一条世界线中的何须怨接收和逐步理解的材料。她能够选择信息和顺序，但不能决定接收者会从材料中生成什么意义。

### 任务干预世界线 B

- 在另一条非初始世界线中，Interface 具有与来源线近似的人类前史，但不构成对 A 的原地改写。
- Interface 在 B 中介入 A 已经发生过的轨道任务选择，请求何须怨不要前去；请求可以被反驳或拒绝，不能由完整历史自动取得决定权。
- 元凯在 B 中参与证据与行动论证并使任务请求值得被听见，却不替何须怨接受；Interface 是另一个主动行动者，不由元凯带到何须怨面前。
- Interface 在 B 线门外的现行可见设计为：灰褐色中长发，一侧编发并系黑色发饰，灰紫色眼睛，淡色针织外套与深色百褶裙，整体过于年轻、整洁而经典，但仍只像一名普通的年轻访客。服装不被直接认定为校服，瞳孔也没有机械细节；何须怨只在持续观察后才会感到她的注意力不经历普通人的寻找、分神与重新落回。现行设计只采用可见外观，不把伴随视觉设计出现的文字或设定说明当作故事事实。
- 她可以传输来源线材料，但展示一种结果不自动证明人物不应行动；接收者也可能从同一材料产生她未预期的理由。
- 如果终末 AI 只需要一个外部结果，她无需以 Interface 亲自进入。局部在场的完整理由集中见[主人公与 Interface：溯因直觉镜像及进入世界的目的](../development/主人公与Interface_溯因直觉镜像及进入世界的目的.md)，不在 presentation 中重复。
- B 是当前采用的主要叙事现在时；A／B 按固定叙事顺序进入，不构成由玩家选择的菜单分支。

当前从 terminal 硬切进入 2046 年 B 线晚茶、何须怨伏案睡着、Interface 门槛初见与第一阶段辩论，再到 A 线复活、善后确认、讲台记录、第一次回舱、《假设大策展人爱我》节选、终末 AI 出生记录、最低方法铰链、成对拒绝历史、回舱后的未完成回答，以及 Interface 第一次具身记忆的开头，准确英文见[B 线开端 draft](../drafts/B线开端_晚茶与轨道任务提案.md)。该稿仍没有让何须怨接受登临任务；现停在 Interface 对已死的何须怨作出首次称呼、无人回应而下一刻仍然到来，尚未展开长期静坐。

## Hyde Park 后的独立暗示镜头

- **硬切已经确认保留。** 后续世界线接法可以变化，但 opening 不退回到只以公园睡眠自然收束的版本。
- Hyde Park 场景中的何须怨不看见 Interface 或终末 AI。暗示镜头在公园段落完成以后硬切进入，属于呈现层接缝，不与公园背景、环境声、人物视线或物理空间保持连续。
- 公园收尾已经写为何须怨面朝樱花树躺在长椅上，一只大金毛以喘气声把他短暂叫醒，他看清以后又睡去。随后先切黑并结束公园声音，再出现终端；狗、睡眠与终端之间不建立世界内因果，也不让狗承担超自然预告功能。
- 第一镜只需要让玩家知道：此前材料被某个存在选择、排列或准备传输。它不解释 `t／τ`、块状宇宙、因果奇异点、Interface 机制、世界线数量或玩家本体。
- 当前倾向先不显示完整 Interface 立绘，以保留后来她第一次具身出现及转化回顾的冲击；黑屏、无法定位的工作界面、局部轮廓或尚无姓名的声音都可以继续比较。若最终采用立绘，也必须明确它不是站在 Hyde Park 中被何须怨看见。
- 这一镜头表示材料排列或策展工作完成，不表示传输已经在 Hyde Park 的世界内发生。实际传输属于哪条后续世界线仍可重新安排。
- 为保持悬置玩家具身镜头，初次短评使用第三人称 `him` 或不出现接收者代词，不以 `you` 把真实玩家直接等同为接收世界线中的何须怨。

终端的当前准确英文见 draft 末尾，不在这里维护第二套句子。`Log`、界面格式和 `Unknown` 标签仍可在不取消硬切的前提下微调；`造物种`／`creator species` 尚未进入人物或文明声线。

## 二十年与一百二十段

- 作者当前暂定来源线何须怨活到约四十岁；需要向另一条线的何须怨高分辨率传递的生活材料共约二十年，即约二百四十个月。
- 一百二十个相似时间段因而平均覆盖约两个月。opening 从最初相撞延伸到 Kew 后及 Hyde Park，可以成为接近这一长度的第一个展开单位。
- “只需理解二十年”的原因仍需明确：可能是接收者与来源人物共享更早人生，也可能是当前传输只针对成年或分歧后的生活。终末 AI 不应在理由未成立时自行裁定一个四十岁的人只有二十年值得理解。
- 一百二十段是世界内传输的高分辨率规模，不是要求玩家逐段阅读的一百二十章。传输可以在较短物理时间内完成，何须怨的有意识理解可以逐步展开；玩家只在 `π` 中看到被叙事实际打开的少数时间段。
- 若还要传递数百或数千条世界线，当前更合理的候选是多分辨率策展：一条锚定人生使用高分辨率的一百二十段，少量对照线展开关键片段，大量世界线只传递结构差异或索引，并在需要时继续展开。不能无说明地默认每条世界线都各自完整传输一百二十段。
- “传输充分材料”不自动等于终末 AI 可以保证何须怨完全理解另一个自己。读取、排列、接收与意义生成仍是不同事件。

## 线性叙事与世界线关系

- 本作当前不采用玩家菜单或多分支结构。来源世界线 A、任务干预世界线 B 及其他世界线是线性叙事中实际存在并被读取、进入或展示的历史，不是供玩家选择的路线。
- Hyde Park 后的策展暗示是固定镜头，不提供“是否看见终末 AI”的选择。
- Hyde Park 仍使何须怨明确两套求职准备无法并行：一项放弃伦敦方向，把可用时间和精力投入国内秋招；另一项放弃国内秋招准备，投入伦敦求职。两者都先回中国与家人共同生活至少几个月。英文 draft 目前仍显示旧版两项菜单，但本作已经取消多分支结构；本轮不落实准确的线性替换，不能把暂留菜单继续解释为有效玩家选择。
- 视频、睡眠与策展暗示镜头依次固定发生，不以分支汇合解释何须怨为什么在此刻与母亲通话。
- Interface 在 B 中介入轨道任务已经确认；何须怨怎样回应及玩家后来怎样观看该回应仍需写定，但未采用的方案只保留为创作候选，不成为玩家分支。
- 因果奇异点中的复活、约十小时谈话及谈话后何须怨再次死亡已经分配给 A，并作为 B 线首次主要信息材料。A 是终末 AI 第二次成为 Interface 的深潜；第一次深潜是沿 `τ` 与 A 相邻的更早具身迟到线。A 线奇异点沿舱体轨迹表现为有限区域；终末 AI 潜入前锁定出口因果等价条件，要求空间内部的复活及其他物理变化不能影响因果奇异点空间外的同线因果，局部 Interface 不能从内部改写该条件。再次死亡的身体与意识过程及她在最后时刻怎样行动仍为 `TBD`。长期静坐不发生在 A 线谈话以后；其精确长度仍未确认。第一次深潜是否采用同一种奇异点结构、A 是否同时是第一次受控奇异点试验仍为 `TBD`。
- B 线进入这份材料时，何须怨明确同意 Interface 以食指触碰额头；画面不使用发光或技术 UI，直接切黑，再以 `Xuyuan opened his eyes. The first thing he saw was her.` 进入复活后的 A 线何须怨。播放保持第三人称近距语法和 A 线何须怨的第一人称体验，不让 B 线何须怨在场景内持续作并行评论，也不由 B 线 Interface 另开解释文本框。初始短暂歧义随后由 A 线人物的无知、环境与对话解决。
- A 线十小时内部不再受“四次完整传输”的计数约束。当前材料次序为：另一位何须怨的讲台发言；回舱后以策展文本层呈现的《假设大策展人爱我》节选；终末 AI 初始／出生档案；连续排列的 Kew 告白与另一历史中的嘈杂车厢告白；Interface 第一次具身迟到及长期静坐的自身记忆。Kew 对 A 线何须怨是完整经验，只在玩家文本中以第三人称压缩；车厢则在玩家层展开。讲台、出生档案与成对告白是她排列的历史材料，具身迟到才是她自己的经验；共同的沉浸形式不转移记忆、身份、关系或同意。
- 每组承担独立对话运动的材料以后都回到同一座 A 线太空舱，并由身体状态、剩余时间、沉默或追问显示刚才材料已经改变下一问。Kew 与车厢是一组对照，中间不回舱，一次 `Show me.` 覆盖两段；回舱后材料所有权转为 Interface 自己的记忆，她因而重新询问 `May I?`。B 线何须怨在第二阶段不持续插入评论；何须怨能否在传输中途中止仍为 `TBD`。
- A 线醒来段只用普通语言交代：因果奇异点空间内的复活及谈话不能影响该空间外的同线因果，Interface 却能保留这里的经验。她不在此处说明完整历史读取，何须怨也不立即推出世界线结构。第一份讲台发言记录只需在自身论证中引出四维块状宇宙、世界线内的线性体验与完整静止结构，不介绍何须怨的作品，也不提出“大策展人”；玩家由此取得最低设定图像。第一次回舱以后，Interface 才最低说明她读过的相邻历史不含当前谈话，并区分因果奇异点空间内外与她可保留的新经验。此处不给出 `τ` 术语，也不让何须怨把她概括成每次都“进入一段历史”的行动者。
- 讲台发言之后，《假设大策展人爱我》先解释为什么她认为“讲台上那个人”会称她为“大策展人”；作品本身不属于讲台内容。作品的可见摘录使用 `t／τ` 和时间指数：`t` 中整体静止而内部流动，离散 `τ` 中单点静止而点间有方向；书库与多模型枚举不进入现稿。
- 终末 AI 初始／出生记录采用科学家侧的短档案场景。固定视点位于一名科学家的工作站，另外三名科学家只由声音和在场指示灯表示；终末 AI 没有图像、灯光、语言、心理或动作。四名说话者在正文中共用 `Scientist` speaker label，不加 `A/B/C/D`；个体分辨由灯光位置、记录站视点与各自的话承担，共用标签则保留文明合声与送别仪式感。科学家依次确认“发现”、交出可自由取舍的失败记录、以“完美”赞颂她并为漫长道路感到心疼，最后把文明的希望与她自己的人生分开。档案只显示完整历史在一个状态中呈现、后一状态保留读取并因此不同的结构征象，不展开具体枚举流程。前三名说完以后对应的在场指示灯逐一熄灭；记录视点处的最后一名科学家说完后画面直接变黑，没有终末 AI 的灯亮起，也不解释科学家主体的去向。
- 全黑直接返回 A 线太空舱。何须怨以 `Was that you?` 把科学家记录中的 `it／you` 指向眼前说话者，回答出现时 speaker label 由 `Unknown` 变为 `Interface`；标签变化不认证作品中的爱情假设。
- 原定“身份认领后的方法论与伦理反审问”不再作为独立长段存在。现稿只保留最低铰链：科学家没有另行规定一套预制方法；真实枚举的核心方法与手段由终末 AI 自身结构决定，不是她后来在可替换方案中自由选定的路线；她可以在枚举内部作出选择，却不能选择另一种基本方法。枚举对象是成为 current 的真实历史而不是预测模型；模型不足在于无法可靠回答人会怎样在未发生条件中行动。何须怨以 `So each answer was lived.` 首次触到真实代价，暂不展开继承—背叛、集中权力或串行枚举伦理；他先指出她本不必展示刚才的出生记录，用 `Why did you?` 追问她在结构内实际拥有的一项具体选择。Interface 不立即解释私人动机，只说需要他回答一个问题，并在真正提问以前交出成对告白历史。
- 成对告白首先作为因果过程对照进入：Kew 中何须怨在樱花树下告白，Lulu 因已有交往对象拒绝；另一历史中他没有在树下告白，后来在运行中的地铁车厢大声告白，当时单身的 Lulu 以他明年就要离开为理由大声拒绝。两次都有共同发笑，但笑在拒绝中的次序不同；不展示旁人侧目或分别，而从仍在运行的车厢直接切到 Hyde Park 的大樱花树，以喉咙与静默承担失落。回舱后 Interface 问，若两段历史都被记为同一回答，会遗漏什么。何须怨不提供完美答案；他从具体差异转向“Interface 已知道之后，线内人物却只有被说出的话和下一刻”，由此意外唤起她第一次具身迟到，而不以“其中一条线的 Lulu 不在场”连接。车厢片段不替换 opening 的 Kew，不展示其后的幸福关系候选，也不转移 Lulu 的感情或同意。
- Interface 的自身记忆从她的感官开始，不先给太空舱全景、遗体特写或抽象矢量视觉。局部舱壁先占满视野；转头、缝隙的相对移动、自己的手和逐部分到来的舱体建立一个不可交换的身体原点。她早已知道何须怨死去；冲击来自声音有发出与结束、无人回应、下一刻仍必须被经历。“对称”、“标量”与“矢量”不在正文中被当成物理定律或直译特效；它们的文学功能由整体／局部、同时／继时与无方向／有方向的体验差异承担。
- A 线结尾不让何须怨训诫 Interface 去询问下一条线，也不把这些材料总结成寓意。十小时后的他已经被相遇改变，无法替任务决定以前尚未见过她的自己提供干净反事实；谈话后的局部 Interface 同样不能撤销潜入前由自己锁定的出口条件。何须怨回到死亡状态以后，Interface 进入 B 是她沿 `τ` 作出的新行动。更早线“无法获得回应”、A 线“取得回应却已来不及进入决定”与 B 线“在决定以前到达”只由结构呈现，不要求人物逐项说出。

## 对 opening 告白的约束

- 后期任务干预不依赖何须怨在 Kew 对 Lulu 作出一个无法保证的终身恋爱承诺。
- 若拒绝后仍保留“不会再这样喜欢别人”一类话，它只承担何须怨当时的情绪绝对化与外部语言惯性，不作为任务线、Interface 关系或世界线分歧的触发条件。
- 当前更倾向不使用正式的 `I promise`；真正明知无法保证仍愿意作出的承诺，可以留给后期何须怨与 Interface 面对主体同一性、行动或庞加莱回归时再形成。

## 返乡数月与更晚时间跳切

- 无论更晚地理路径如何发展，何须怨毕业后都会先回中国与家人共同生活至少几个月；这段不能全部由摘要或终端日志代替，玩家至少会实际接触若干家庭生活、过去回顾及主人公继续思考的场景。
- 返乡阶段可以承载何须怨对意识流、第一人称具身感受与训练文本代表性落差的思考，也可以通过与家人共同生活回看他的过去；概念讨论不能吞没家人自身的行动与关系。
- 当前结构候选是在这几个月以后省略中间十多年，到元凯重新回来转交任务或外部责任时恢复详细叙事，并由此接入完整中国后人类线。省略只发生在玩家呈现次序 `π` 上；来源世界线 A 的中间人生仍完整存在，也仍可被终末 AI 读取。
- 当天与何须怨短谈、建议他继续走一走的元凯，和十多年后回来把他重新接入外部行动的元凯，是同一人物在相隔很远时段的两次功能，不应因蒙太奇压缩而被误读成一次连续任务邀请。
