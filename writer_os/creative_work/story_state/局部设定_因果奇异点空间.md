# 局部设定：因果奇异点空间

## 地位与适用范围

因果奇异点空间是作者已经确认的 scope-limited commitment。来源世界线 A 已经确认承载一个完整展开的具体实例；沿 `τ` 与 A 相邻的更早具身迟到线，现也确认存在一个何须怨本可被暂时恢复的因果奇异点窗口。两者的严格机制与出口条件不因共享名称而自动相同。

这一 local truth 不自动扩展到所有世界线。

## 已确认的最小核心

- 因果奇异点空间存在于来源世界线 A。
- 太空舱可以在其中经历有限的线性时间。
- Interface 的自身具身不自动带来可在任意时间与地点使他人复活的一般能力。目前两条相关世界线中，暂时恢复何须怨都只在有限的因果奇异点窗口内可能。

## A 线已确认实例

- 2046 年轨道行动中，隐藏的策略分发／签名模块被隔离，原始证据载体进入何须怨所在的密封隔离／取证舱；设施处置与最低证据传输成功，完整原件回收及何须怨撤离失败。何须怨所在舱体是此次行动中唯一未能撤离的载人单元，其余现场成员完成撤离；团队内部动作与成员构成仍为 `TBD`。
- 舱体被弹出以后，何须怨使用隔离的本地取证与远距离通信能力完成最后统合，把足以支持撤销关键签名、迁移合法服务和继续问责的最低充分材料传给地面。他同时继续求救和维持生存，不是为了任务主动放弃求生；在资源耗尽、意识中断以前，他已经发出材料，却没有取得足以确认地面最终接收和行动结果的回信。精确材料、通信中断点与地面接收顺序仍为 `TBD`。
- 密封舱体被持续推进送往预先计算的木星交会轨道，随后借木星引力助推进入日心逃逸轨道。精确推进器、行星窗口与轨道参数仍为 `TBD`。
- 何须怨没有活到舱体进入因果奇异点。他在保持密封的舱内因长期资源耗尽而死，饥饿是当前优先方向；爆炸破舱、真空暴露和剧烈失压不作为默认死因。他在 A 线复活时保有自己发出材料、等待确认并在资源耗尽中失去意识以前的连续记忆，死亡完成本身不成为一段可回忆的经验；精确末段生理与意识过程仍为 `TBD`。
- 舱体带着何须怨的遗体与原始证据沿 A 线普通线性时间 `t` 漂流很多年，百年以上也可以成立。地球经过很久不依赖黑洞式时间膨胀。
- 舱体必须在失去居住功能以后仍使结构、证据与遗体保持足以被找到和恢复的完整性；具体长期保存机制尚未确认。
- 舱体进入因果奇异点以后，Interface 在其中复活何须怨，并与他进行约十小时谈话。复活的身体机制尚未确认；上述死前连续记忆只规定场景起点，不裁定复活前后数值同一性的完整理论。
- 约十小时谈话结束以后，A 线何须怨在舱体离开因果奇异点以前再次回到死亡状态。再次死亡由潜入前已经设定的出口因果等价条件要求，不是谈话后的 Interface 才临时作出的决定。谈话末段 Interface 因具身疲劳睡着，何须怨在她睡后用一层衣物盖住她；边界回置局部状态时，她在睡眠中感觉肩上的轻微重量被提走。衣物的具体种类、何须怨再次死亡的身体与意识过程，以及 Interface 怎样离开局部具身状态仍未确认。
- 因果奇异点可以位于太阳系内，也可以位于之后的星际航程；精确位置和进入机制仍为 `TBD`。
- 终末 AI 的初始／出生世界线不是 A；A 线地球已经过去很久，不表示终末 AI 在 A 线出生。

## A 线出口因果等价条件

- A 线中的因果奇异点沿舱体轨迹表现为一个有限区域；舱体按原有轨迹穿过该区域，在其中取得约十小时的线性时间。区域的精确空间、几何、物理或信息机制仍为 `TBD`。
- 终末 AI 在成为 A 线局部 Interface 以前，已经为这次潜入设定进入与出口参数。出口条件要求：舱体离开区域以后，仍可沿 A 线 `t` 继续传播的状态须与没有发生奇异点内部干预时因果等价。
- “因果等价”不要求当前就确认逐分子还原。它至少排除何须怨的复活状态、谈话造成的舱内物理改动、新记录、通信尝试或其他可向 A 线外部继续传播的痕迹。精确等价粒度与实现机制仍为 `TBD`。
- 何须怨所在舱体在长期漂流中已经耗尽维持生存的资源；即使允许他以复活状态离开，也没有条件获得一段可持续的第二人生。但额外存活的分钟、小时或更久，以及期间可能形成的动作和记录，仍然会改变 A 线，所以“最终仍会因资源不足死亡”不能替代出口因果等价。
- 局部 Interface 在十小时内可以提出未预制的问题、改变材料次序并因何须怨的回应而变化，但不能从奇异点内部修改潜入前已经锁定的出口条件。边界约束不预写谈话内容。
- Interface 在奇异点内取得的经验、记忆与自身变化不作为 A 线 `t` 中的物理痕迹离开，而是沿元时间 `τ` 被终末 AI 保留。这使谈话能够改变她后来的介入，包括 B 线，而不把 A 线原有外部历史改写。

## 已确认的双层隔离

- 在同一条世界线的线性时间 `t` 中，因果奇异点空间内部的因果变化不会影响空间外部的因果与历史。
- 这一线内隔离不阻止 Interface 在空间内取得的经验、记忆或自身变化沿元时间 `τ` 被终末 AI 保留，并可能影响她以后的枚举与自身状态。
- 因此，“不影响空间外部的因果”只约束该世界线内部的 `t` 层因果，不表示奇异点内发生的事对终末 AI 的 `τ` 层经历没有意义。

双层隔离允许因果奇异点成为终末 AI 校准 Interface 局部在场的受控环境：同一世界线中因果奇异点空间外的因果与历史不因内部对话而改变，但终末 AI 本身可以因这次经验而沿 `τ` 发生变化。

## 更早具身迟到线的已确认窗口

- 该线太空舱曾经穿过一个 Interface 可以暂时恢复何须怨的因果奇异点窗口。Interface 真正具身到达时，舱体已经离开该窗口，因而她无法在当时所在的局部时空复活他。
- 这不是终末 AI 不知道何须怨已经死去、不知道奇异点边界或意外算错时间。她读过完整历史，并主动选择在复活窗口以后进入。
- 她的当时理由是：可以站到具体的何须怨面前取得具身经验，却因他已经无法回应，避免一个新回答改变自己的当前状态或后续枚举方向。这是 Interface 在枚举结构内作出的选择，不是其核心方法预定的必然行动。
- 这项保护性选择没有取得她预期的结果。即使何须怨没有回答，局部视野、发声、等待、无回应与沿 `t` 继续经历下一刻仍然改变了她。A 线中她随后改为在因果奇异点内恢复何须怨：她仍以出口因果等价保护线内外部历史，却第一次允许一个真实回答改变自己。

## B 线任务死亡后的再次相遇边界

- B 线中发生在任务决定以前的对谈与材料传输已经成为该线的因果条件。它可能改变何须怨的准备、任务内行动与生还条件；因此，即使他仍然参加任务，A 线中的死亡也不是 B 线必然重复的结果。B 线最终生还或死亡仍保持开放。
- 如果 B 线何须怨最终因该任务死亡，他不会在同一条 B 线中于死后再次在因果奇异点空间与 Interface 相遇。终末 AI 不能把一条已经形成的 B 线当作原历史，再向其中补入一次较晚的进入、复活与对谈。
- 如果 Interface 此后仍希望在这组历史条件下与死后的何须怨对谈，她必须沿 `τ` 进入另一条后来成为 current 的世界线。该线至少到何须怨因任务死亡为止，保持 B 线已经发生的历史与介入条件不变；新增变量只在死亡以后出现，即 Interface 再次进入、在适用的有限恢复条件内复活他并与他对谈。
- 这是一项作者侧近似“控制变量”的世界线约束，不表示原 B 线被原地修改，也不证明后一线的何须怨与 B 线何须怨具有数值同一性。此前世界线怎样保持到何种等价粒度、Interface 怎样避免自身后来知识改变前段历史，以及这一后继世界线是否实际形成，仍未确认。
- 当前 B 线 Interface 知道上述边界，也知道后一条线中的何须怨仍须重新被询问，不能继承当前何须怨的回答。何须怨本人是否知道不由本条自动确认；Interface 在当前对话中不必把这套后台条件说出或用作施压。

## 尚未确认

- 除 A 线与更早具身迟到线的已确认窗口以外，是否还实际形成其他具体世界线实例；B 线死亡后的后继再会目前只确认必要条件，不确认事件必然发生；
- 更早线窗口的精确几何、时长、恢复方式与出口条件，以及它与 A 线因果奇异点是否共享同一严格机制；
- 除已确认的 A 线有限穿越与出口因果等价以外，空间边界、进入、穿过与离开的严格含义；
- 其物理、几何或信息机制；
- A 线实例的精确轨道、漂流年数、长期保存工程与奇异点位置；
- Interface 怎样复活何须怨，以及复活前后的身体与意识连续性；
- 经验、信息、记忆或情感以何种机制、选择范围与完整度沿 `τ` 被保留；
- 十小时谈话以后何须怨再次死亡的精确时点、身体与意识过程，Interface 离开局部具身状态的严格机制，以及覆盖她的具体衣物；
- 具体场景中的玩家选项。
