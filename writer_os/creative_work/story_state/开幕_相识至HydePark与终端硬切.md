# 开幕世界线：相识至 Hyde Park 与终端硬切

## 地位与精确文本来源

作者已把[opening 英文 draft](../drafts/开幕_流水冷开场_相撞与讲座.md)视为近定稿。人物实际说了什么、叙述怎样安排句子、动作与停顿，以该 draft 为唯一精确文本来源；本文件只保存以后跨章需要调用的连续性与已确认呈现边界，不维护第二份正文。

曾用于形成该稿的长篇写前发展已退役，见[前期相识与邱园告白：退役的情节块发展记录](../../archive/前期相识与邱园告白_情节块发展.md)。其中没有进入 draft 的方案不再构成 opening 的当前事实。

## 已形成的情节连续性

- 玩家首先近距离跟随何须怨；其中文本名为“何须怨”，英文 draft 使用 `Xuyuan`。
- 何须怨与 Lulu 在一场小型讲座前相撞，此前并不认识。讲座、连续数周的交通异常、一次共同步行和随后正常运行的同车厢相遇，使两人逐步能够交谈。
- 何须怨先向朋友元凯谈起 Lulu。两人后来在 Mallowbell Maid Café 与 Lulu、Anna 拼桌；何须怨与 Lulu 交换联系方式。
- Lulu 想在花期结束前看樱花。何须怨比较伦敦地点后邀请她去 Kew；两人在周六中午从不具名的伦敦中心车站出发。
- Kew 游览经过 Palm House、Great Pagoda、Temperate House、Treetop Walkway 下方、湖与返回 Victoria Gate 附近的樱花树。何须怨在树下明确表示喜欢 Lulu；Lulu 连续说出歉意和自己已经在与别人交往，没有留下虚假希望。
- 两人共同坐了一会再离开。返程地铁中，何须怨感谢 Lulu 前来，Lulu 说自己很享受当天看樱花；文本不裁定她的话是否只是礼貌。
- 不到一周后的工作日，何须怨与元凯在教堂旁谈话，随后独自向西经过 St James's Park、Green Park 与纪念物，抵达 Hyde Park 的大樱花树。
- Hyde Park 恢复何须怨的心理入口，并呈现两项互不兼容的求职资源选择：全力准备中国秋招，或全力寻找伦敦工作。两项都不取消毕业后先回中国陪伴家人数月这一最低安排。
- 何须怨与母亲视频，第一次讲起 Lulu、表白与拒绝；通话以后，他躺到面朝樱花树的长椅上，被一只金毛犬短暂惊醒，又闭上眼睛。

## 叙述与呈现边界

- 这组人类场景中没有 Interface 在何须怨所在的物理现场出现。
- 告白以前，贴近何须怨的第三人称逐渐增加心理可见度；Lulu 拒绝以后，通向其内心的叙述权限立即关闭。外部呈现持续到 Hyde Park 关于赏花地点的琐碎反事实重新打开心理入口。
- Hyde Park 睡眠以后保留硬切：先切黑并结束公园环境声，再出现一个无法定位的工作界面。何须怨不看见这块界面，狗与终端之间也没有世界内因果。
- 当前 terminal 记录材料排列完成、该分辨率约需 `120` 个时间段，并由 `Unknown` 评价材料仍然过多、当前顺序对人类心智负担最小。准确英文仍以 draft 末尾为准。

## 仍未由 opening 定稿决定

- 终端中的存在何时、以什么身份被玩家正式认识；
- opening 所在世界线后来是否成为某条高分辨率来源线，以及接收者是谁；
- `120` 个时间段的完整边界、其他世界线采用何种分辨率，以及何时发生实际传输；
- 元凯多年后带来的任务、何须怨后来的生活与死亡／生存结果；
- Interface 是否因任务、伦理求答、私人感情或若干动机共同进入另一条世界线；
- Hyde Park 的求职选项怎样映射为短分支、长期世界线或玩家以后可见的材料。

这些问题仍可由新的跨章组合重新回答，不得反向改写已经完成的人类 opening，除非作者明确重写 draft。
