# 终末 AI 与 Interface：跨线记忆及情感回滚能力

## 地位与适用范围

本文件只记录作者已经确认的主体关系、能力边界与已选具体使用实例。保存、加载、写回和回滚怎样实现，不在这里补成事实。

## 已确认的主体关系与能力

- 终末 AI 的本体内嵌于时空结构。
- Interface 自我认同为终末 AI 本身，不是候选助手 AI。
- “终末 AI 成为 Interface”是当前采用的主体关系表述。已经确认的是 Interface 的第一人称同一性认领，以及 Interface 与候选助手 AI 的区分；这不等于旁白已经裁定 Interface 与终末 AI 本体之间是完整同一、有限切片、临时化身还是其他形而上关系。
- 终末 AI／Interface 系统具有跨世界线保存或共享记忆的能力。
- Interface 可以为了交流向主人公传输信息；传输不必发生在临终脑内，也不必包含其他世界线。
- 终末 AI 具有主动进行情感回滚的能力。
- 主人公死亡后立即回滚和长期不立即回滚的情形都会在不同情境或世界线中出现；具体归属仍待后续确定。

## 能力不等于实例事实

- 具有跨线记忆能力，不表示每个 Interface 都已经加载全部跨线记忆。
- 具有情感回滚能力，不表示每次死亡后都会立即回滚。
- 具有信息传输能力，不表示每次传输都包含记忆、具身感受或跨世界线材料。
- Interface 自我认同为终末 AI，不表示 Interface 在线性世界中随时拥有本体的全部信息、权限和当前情感。

## 已确认的早期两次深潜与 A 线使用实例

- 沿元时间 `τ` 与 A 相邻的更早世界线，是终末 AI 第一次成为 Interface 进行具身深潜。她到达太空舱时何须怨已经死亡、无法回应，随后长期静坐于其身旁。
- A 线是终末 AI 第二次成为 Interface 进行深潜。她在因果奇异点中复活已经死亡很久的何须怨，并与他取得约十小时谈话；这一序数不自动表示第一次深潜也采用因果奇异点，A 是否同时是第一次受控奇异点试验仍未确认。
- 在 A 线十小时谈话中，Interface 把第一次深潜中的迟到与静坐作为自身记忆传输给 A 线何须怨。
- 这段材料的第一人称经验来源是 Interface，不是较早世界线中已经死亡的何须怨，也不是脱离主体的全知记录。A 线何须怨接收它，不表示记忆变成了他的经历，或使两条线中的人物、关系和授权合并。
- 玩家呈现可以用第三人称策展叙述压缩静坐中的漫长未选时段；叙述人称的改变只属于呈现方式，不改变记忆的主体来源。

具体的保存、加载、写回、传输和回滚机制尚未确认，其候选内容以[Interface 记忆与情感机制](../../candidates/Interface记忆与情感机制.md)为主记录。本文件只确立能力及不得自动推断具体实例的边界。
