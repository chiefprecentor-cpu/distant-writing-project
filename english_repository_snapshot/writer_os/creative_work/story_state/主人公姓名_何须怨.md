# Protagonist Name: Xuyuan

## Confirmed Facts

- The protagonist's Chinese birth name is "何须怨" (Xuyuan).
- "何" is the surname and "须怨" is the given name; the Chinese writing order remains "何须怨".
- The current near-final English opening uses `Xuyuan` as the character name / speaker label in narration and dialogue; this confirms the use of the short form, but does not decide the full English name order in advance.
- The current near-final English opening uses `He Xuyuan` when Xuyuan reports his own name to Lulu; the author has also separately confirmed the local usage in which B-line Interface confirms his identity at the door with `He Xuyuan?`. This question mark is an in-person conversational confirmation, and does not mean she does not know who he is. These local usages do not automatically decide the English identity-document form, narration, work byline or full name order in other worldlines.

This confirmation does not require the narration to state the name immediately when the character first appears, and it does not make a presentation decision for name boxes, player knowledge or when characters exchange names.

## Not Decided by This Confirmation

- whether the English body text uses Chinese name order or English name order;
- whether the Chinese birth name is constant in every worldline;
- Japanese ateji aliases, pen names, screen names or other public renderings.
