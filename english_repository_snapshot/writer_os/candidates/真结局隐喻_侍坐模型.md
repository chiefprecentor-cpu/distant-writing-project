# True-Ending Metaphor Candidate: The "Attending While Seated" Model

## Status

This is an inactive metaphor candidate for the true ending. It preserves the possibility of using the "Zilu, Zeng Xi, Ran You and Gongxi Hua attending while seated" passage from *The Analects*, "Xianjin", as a model for the ending's relationships and structure. It does not mean that the ending event, dialogue, space, character mapping or reenactment of the classical text has already been fixed.

At present, it is not assigned to a specific worldline, and it does not automatically merge with [Ending Candidate: There Is Still Something to Do and the Terminal AI Rekindles Hope](终局_仍有可做之事与终末AI重燃希望.md). The two candidates can illuminate each other later, but their adoption decisions remain independent.

## Minimum Scope Confirmed by the Author in This Round

- "Attending While Seated" is preserved as a **true-ending final metaphor candidate**, not as an allusion for an ordinary mid-work scene.
- It is used only as a model. It does not require the characters to correspond one by one to Confucius, Zilu, Zeng Xi, Ran You or Gongxi Hua.
- At present, only the protagonist and the Grand Curator are provisionally confirmed as present.
- It is not confirmed which positions, if any, the protagonist or the Grand Curator occupy in the original text.
- Other characters are not automatically added simply because the original is a multi-person scene of attendance.

## Usable Boundary of "As a Model"

In later development, it is possible to examine the relational rhythm, question-and-answer structure, expression of aspirations, loosened positions of judge and judged, and the way grand affairs finally return to actions or scenes of shared life that "Attending While Seated" can provide. These are only possible literary functions supplied by the model, not an ending interpretation already confirmed in this round.

If the final main work only places the two of them in the same scene, the structural echo of the original can still be retained without forcing the original number of people. If additional characters, the space beneath the tree, a new-world landscape, specific actions or quotations from the original are added later, they need separate confirmation and cannot be derived automatically from this metaphor.

## Status Boundary

Only the minimum relational model above is currently preserved. There is no fixed correspondence between the protagonist, the Grand Curator and the figures in the original text, and character functions, scenes and dialogue not written into this file do not count as candidate content.
