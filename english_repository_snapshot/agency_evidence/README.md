# Agency Evidence

This folder contains public-facing English evidence derived from agency-negotiation audit records for the distant-writing artefact.

The source audit records were produced during the AI-assisted writing process. They analyse visible collaboration traces, Writer OS changes, Git states, author responses and AI-agent actions. The private raw traces are not included here.

## Public Preparation Policy

The public files retain technical and methodological detail where it helps readers understand the artefact. They remove or generalise material that could disclose private working context or local machine identity, including username-bearing absolute paths and private transcript locations.

The records preserve the distinction between external audit commentary and author response. Audit commentary normally refers to the human maker as "the author"; first-person author reflections remain first-person where the source record uses that form. Fictional-character pronouns are unchanged.

## Included Files

- `records/index.md` lists the full English translated agency records and their evidential focus.
- `records/*.en-full.md` are full English translations of reviewed agency-audit records. They provide record-level evidence for the dissertation discussion.

This folder is an evidence supplement. It is not a substitute for the dissertation's own analysis.
