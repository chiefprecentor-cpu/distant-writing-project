# Review a VN Draft

Use this skill when the interaction among craft dimensions matters. A clearly local question about subtext, dialogue, comedy, or rhythm belongs to the relevant specialist skill instead.

For the current distant-writing project, read the shared [aesthetic profile](../interpret-co-writing-signals/references/aesthetic-profile.md). Read the full user-supplied draft scope. Do not replace a large-scope review with analysis of a convenient excerpt.

Match the depth of review and context loading to the user's request, the supplied scope, and the consequences of the decision. Begin with the draft and aesthetic profile. When a specific passage cannot be understood without a missing development or story-state constraint, search for that constraint and read the narrow relevant section, stating the expansion. Broader contextual reading is appropriate when the user requests it or when the draft's structure genuinely depends on it.

## Consult specialist skills selectively

Make an initial integrated reading before loading specialist instructions. When a consequential issue clearly belongs to a specialist lens, consult the relevant sibling skill:

- [explore-subtext-and-distance](../explore-subtext-and-distance/SKILL.md) for interpretation, viewpoint, explanation timing, or ambiguity;
- [workshop-dialogue-and-comedy](../workshop-dialogue-and-comedy/SKILL.md) for character language, conversational action, comedy, or reference openness;
- [shape-vn-rhythm-and-montage](../shape-vn-rhythm-and-montage/SKILL.md) for scene rhythm, silence, repetition, montage, or continuity across cuts.

Load only the specialist guidance that materially changes the review. If different sentence- or clause-level signals in the user's prompt affect what the review should explain, compare, preserve, or change, consult [interpret-co-writing-signals](../interpret-co-writing-signals/SKILL.md). A simple local uncertainty with an otherwise clear request can be handled directly.

Return from the specialist lens to an integrated account. This skill owns the relationships among findings, conflicts between locally good choices, spoken versus player-visible versus production channels, the order in which the player learns information, and observations from a fallible character concealed behind an apparently third-person, near-omniscient surface.

Locate the effects and tensions that matter rather than filling a preset number of slots or assuming historical examples are still the only issues. Preserve strengths and purposeful irregularities. For genuinely open choices, present viable directions and their costs, then give a provisional recommendation and what would reverse it.

Review does not authorise edits. If implementation is requested, make a focused patch, report any changed semantic consequence, and leave unresolved aesthetic choices visible rather than silently deciding them.
